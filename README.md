# Guia de Estudos Interativo (demo)

Protótipo de um guia de onboarding para alunos de um curso online, em formato de app para celular. **Todo o conteúdo é fictício** (um curso de inglês inventado) e foi criado para demonstrar a solução, sem nenhum dado ou material de empresa.

## O problema que inspirou o projeto

Em atendimento a alunos, percebi que o onboarding tinha poucas interações e que parte dos pedidos de cancelamento citava dificuldades como "não sei usar a plataforma" e "não sei por onde começar a estudar". Antes de construir, cruzei esses dados em planilha. O guia nasceu dessa análise.

## O que a demo faz

- **Hoje:** o aluno escolhe quanto tempo tem (20 a 60 min ou 2 a 4 h) e recebe uma rotina com checklist e barra de progresso. O progresso fica salvo no navegador.
- **Onde fica:** mostra o caminho de cada recurso na plataforma.
- **Semana:** sugestão de organização, com o dia de hoje destacado.
- **Dicas:** regras e perguntas frequentes que abrem e fecham.
- Modo claro e escuro automático, e layout pensado para celular.

## Como foi feito

- HTML, CSS e JavaScript em **um único arquivo** (`index.html`), sem bibliotecas, criado com apoio de IA.
- O código é **comentado em português** e os textos ficam reunidos em um bloco no início do script, para que alguém sem experiência em programação consiga editar o conteúdo sem quebrar a página.

## Como abrir

Baixe `index.html` e abra no navegador. Se o repositório estiver com o GitHub Pages ligado, o link do site fica em *Settings → Pages*.
